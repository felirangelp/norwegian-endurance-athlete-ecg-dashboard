Técnicas Implementadas para el Taller FFT EEG:
Para el análisis de señales EEG, implementé un conjunto integral de técnicas de procesamiento de señales digitales siguiendo exactamente la metodología explicada por la profesora. Utilicé la Transformada de Fourier Rápida (FFT) como técnica principal para el análisis espectral, implementando el algoritmo exactamente como se describe en MATLAB pero adaptado a Python usando scipy.fft.fft(). Aplicé técnicas de preprocesamiento incluyendo normalización de señales, cálculo de vectores de frecuencia con fftfreq(), y manejo de frecuencias positivas únicamente mediante P1 = P2[0:L//2+1] y multiplicación por 2 para conservar la energía de frecuencias negativas. Para el análisis de bandas de frecuencia EEG, implementé técnicas de filtrado digital usando filtros Butterworth (scipy.signal.butter) para separar componentes Delta (0.5-4 Hz), Theta (4-8 Hz), Alpha (8-13 Hz), Beta (13-30 Hz) y Gamma (30-100 Hz). Utilicé el método de Welch para calcular la Densidad Espectral de Potencia (PSD) con scipy.signal.welch(), técnicas de detección de picos espectrales con scipy.signal.find_peaks() para identificar las "montañitas" mencionadas por la profesora, y análisis de ventanas deslizantes para monitoreo temporal de potencia en bandas específicas. Para aplicaciones clínicas, implementé técnicas de detección de actividad epiléptica basadas en análisis de frecuencias gamma y umbralización estadística, análisis de oscilaciones alfa para tareas de atención usando filtrado en banda específica, y técnicas de visualización interactiva con Plotly para crear dashboards HTML que permiten zoom, pan y análisis interactivo de los resultados espectrales.


TÉCNICAS IMPLEMENTADAS EN EL PROYECTO ICA ECG
En este proyecto de Análisis de Componentes Independientes (ICA) para ECG materno-fetal, implementé un conjunto integral de técnicas de procesamiento de señales biológicas que abarcan desde los fundamentos teóricos hasta aplicaciones clínicas avanzadas. La técnica principal es FastICA (Fast Independent Component Analysis) de scikit-learn, aplicada para separación ciega de señales ECG mezcladas, complementada con normalización de datos (centrado y escalado), análisis de independencia estadística mediante información mutua y correlación, medidas de no-gaussianidad usando curtosis como momento estadístico de orden 4, whitening/blanqueamiento de datos mediante descomposición eigenvalores-eigenvectores, detección automática de picos R usando scipy.signal.find_peaks para estimación de frecuencia cardíaca, análisis biofísico de matriz de mezcla interpretando coeficientes como atenuación desde fuentes hasta sensores, validación del cocktail party problem aplicado a señales biomédicas, pruebas de robustez con múltiples inicializaciones, y visualización interactiva con Plotly para generar gráficos HTML profesionales. El proyecto demuestra la aplicación exitosa de blind signal separation en biomedicina, logrando una reducción del 88.9% en dependencia estadística y separación efectiva de ECG materno (80 BPM) y fetal (111.4 BPM) con frecuencias cardíacas dentro de rangos fisiológicos normales, validando experimentalmente todos los conceptos teóricos de ICA vistos en clase.



Técnicas Utilizadas en el Análisis de Señales Extracelulares
El proyecto implementa un análisis completo de señales extracelulares utilizando múltiples técnicas avanzadas de procesamiento de señales biológicas. Análisis de Componentes Independientes (ICA) se emplea como técnica principal de separación ciega de fuentes para descomponer las señales mezcladas de los 3 electrodos en fuentes independientes, permitiendo identificar cuál contiene los potenciales de acción. Filtrado digital paso-banda (300-3000 Hz) se aplica para eliminar componentes de baja frecuencia y ruido, optimizando la detección de spikes. Detección automática de potenciales de acción utiliza umbralización adaptativa basada en desviaciones estándar (3σ) con aplicación de período refractario (2ms) para evitar detecciones múltiples del mismo spike. Spike Sorting mediante clustering K-means clasifica las formas de onda detectadas en diferentes neuronas, utilizando el método del codo para determinar el número óptimo de clusters. Análisis de frecuencia de descarga calcula las tasas de disparo (firing rates) en ventanas temporales de 1 segundo, permitiendo caracterizar la actividad neuronal antes y después del movimiento. Generación de spike trains representa la actividad temporal de cada neurona identificada, facilitando el análisis de patrones de disparo. Estas técnicas combinadas permiten la identificación, clasificación y caracterización de neuronas excitatorias e inhibitorias basándose en sus patrones de actividad durante el movimiento de la extremidad superior.


Técnicas Implementadas en el Proyecto
Para cumplir con los requerimientos del taller de análisis FFT en señales EEG, implementé un conjunto integral de técnicas de procesamiento de señales biológicas utilizando Python como plataforma principal. La técnica central fue la Transformada Rápida de Fourier (FFT) implementada con scipy.fft.fft() para convertir señales EEG del dominio temporal al frecuencial, siguiendo exactamente la metodología especificada en el taller con normalización correcta (P2 = abs(Y/L), P1[1:-1] = 2*P1[1:-1]) y cálculo del vector de frecuencias (f = Fs*arange(L//2+1)/L). Para el análisis de bandas EEG, desarrollé técnicas de cuantificación de potencias espectrales en las cinco bandas características (Delta 0.5-4 Hz, Theta 4-8 Hz, Alpha 8-13 Hz, Beta 13-30 Hz, Gamma 30-100 Hz) usando funciones de filtrado frecuencial (idx = (f >= freq_range[0]) & (f <= freq_range[1])) y cálculo de potencias (np.sum(P1[idx]**2)). Siguiendo específicamente los comentarios de la profesora, implementé técnicas de análisis de resolución frecuencial experimentando con diferentes tamaños de FFT (256, 512, 1024, 2048, 4096 puntos) para estudiar el efecto en la resolución (Resolución = fs/N) y estabilidad de frecuencias dominantes. Para la visualización y presentación de resultados, utilicé técnicas avanzadas de visualización interactiva con Plotly (make_subplots, go.Scatter, go.Bar) y matplotlib para crear dashboards web con múltiples pestañas que responden cada una de las 11 preguntas del taller con gráficas de soporte específicas, incluyendo espectros comparativos, análisis temporal, distribución de potencias por banda, y tablas de resultados cuantitativos. La técnica de programación orientada a objetos permitió crear clases modulares (EEGAnalyzer, FFTResolutionAnalyzer, TallerFFTDashboard) que encapsulan la funcionalidad de carga de datos MATLAB (scipy.io.loadmat), procesamiento FFT, análisis estadístico (pandas.DataFrame) y generación de reportes HTML interactivos, facilitando la reproducibilidad y extensibilidad del análisis según los estándares del curso de Procesamiento de Señales Biológicas.
