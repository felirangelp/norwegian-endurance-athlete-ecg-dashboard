# 🚀 Instrucciones para Habilitar GitHub Pages

## Pasos para activar GitHub Pages:

### 1. Ir a la configuración del repositorio
1. Ve a [https://github.com/felirangelp/norwegian-endurance-athlete-ecg-dashboard](https://github.com/felirangelp/norwegian-endurance-athlete-ecg-dashboard)
2. Haz clic en la pestaña **"Settings"** (Configuración)
3. Desplázate hacia abajo hasta la sección **"Pages"** en el menú lateral izquierdo

### 2. Configurar GitHub Pages
1. En **"Source"**, selecciona **"Deploy from a branch"**
2. En **"Branch"**, selecciona **"main"**
3. En **"Folder"**, selecciona **"/ (root)"**
4. Haz clic en **"Save"**

### 3. Esperar el despliegue
- GitHub Pages tardará unos minutos en procesar el sitio
- Recibirás una notificación cuando esté listo
- El sitio estará disponible en: **https://felirangelp.github.io/norwegian-endurance-athlete-ecg-dashboard/**

## ✅ Verificación

Una vez habilitado, deberías poder:

1. **Ver el dashboard** en la URL de GitHub Pages
2. **Navegar por todas las visualizaciones** interactivas
3. **Acceder a los enlaces** del repositorio desde el dashboard
4. **Ver la información académica** del proyecto
