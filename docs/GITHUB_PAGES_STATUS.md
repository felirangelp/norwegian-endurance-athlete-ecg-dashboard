# Configuración GitHub Pages

## Estado actual:
- ✅ Archivos subidos correctamente
- ✅ index.html presente en la raíz
- ✅ dashboard.html funcional
- ❌ GitHub Pages no habilitado

## Solución paso a paso:

### 1. Habilitar GitHub Pages
1. Ve a: https://github.com/felirangelp/norwegian-endurance-athlete-ecg-dashboard/settings/pages
2. En "Source", selecciona "Deploy from a branch"
3. En "Branch", selecciona "main"
4. En "Folder", selecciona "/ (root)"
5. Haz clic en "Save"

### 2. Verificar despliegue
- GitHub tardará 2-5 minutos en procesar
- Verás un mensaje verde cuando esté listo
- El sitio estará en: https://felirangelp.github.io/norwegian-endurance-athlete-ecg-dashboard/

### 3. Si sigue sin funcionar
- Verifica que el archivo index.html esté en la raíz del repositorio
- Asegúrate de que el branch "main" esté seleccionado
- Espera hasta 10 minutos para el primer despliegue

## Archivos necesarios:
- index.html (página principal)
- dashboard.html (dashboard interactivo)
- manifest.json (configuración PWA)
